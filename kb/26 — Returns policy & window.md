# Returns policy & return window

If you change your mind, you can return most items within **30 days of delivery** for a refund. This is Northbound's own policy and is more generous than the 14-day legal minimum (see "EU right of withdrawal").

To qualify, items must be unused, in original condition, with tags and original packaging. Start a return from **Your account → Returns**.

Some items are handled differently:
- **Sale and clearance items** — see "Sale & clearance items: return exceptions".
- **Faulty, damaged or wrong items** — see "Faulty, defective or wrong item".
- **Personalised or hygiene-sealed items** — non-returnable unless faulty.

How refunds are issued and who pays return postage are covered in their own articles.
